# SEO + Marketing Copy Principles

Status: **shared public-copy guidance**.

ShipLean treats SEO and marketing as complementary constraints. Public copy should preserve verified search intent while making the product's value easier to understand and choose.

The default decision order is:

```text
keyword / SERP evidence
→ search intent
→ page role
→ product offer
→ copy
```

Do not reverse this into:

```text
catchy copy
→ retrofit keywords later
```

## 1. Protect the SEO anchor

For indexable pages, the primary topic and search intent are not disposable marketing space.

Low copy freedom:

```text
URL / route role
Primary keyword / topic
Title
H1
Canonical page intent
```

Medium copy freedom:

```text
Hero subtitle
CTA label
Trust / value signals
Section headings
```

High copy freedom:

```text
Benefit copy
Proof copy
Capabilities
Examples
FAQ
Helpful Guidance
```

A stronger marketing sentence must not weaken the page's keyword mapping or change its search intent without new research evidence.

## 2. Use the public-copy stack

Prefer this hierarchy:

```text
SEO Claim
→ User Benefit
→ Proof
→ CTA
```

Example:

```text
H1
Compress Image to 50KB

Benefit
Meet strict upload limits without destroying image quality.

Proof
Exact target size · Browser processing · No signup

CTA
Upload Image
```

The SEO claim makes the page legible to searchers and search engines. The benefit explains why the task matters. Proof makes the benefit credible. The CTA gives the next action.

## 3. Do not create negative anchors

Do not voluntarily introduce a comparison frame that makes a real but non-essential weakness feel larger.

Examples of avoidable negative anchors:

```text
149 fonts
Only 7 tools
A small collection
A new site
Our growing library
Although we have fewer...
```

If the number or limitation is not required for task completion, compliance, pricing, availability, or an honest product constraint, it does not need prominent placement.

Prefer truthful framing around the actual advantage:

```text
Curated font collection
Carefully selected tools
Verified sources
Clear licensing
Focused workflow
```

This is not permission to hide material restrictions. Required limits, pricing, eligibility, safety, licensing conditions, and other decision-critical facts must remain visible.

## 4. Quantify selectively

Numbers are useful when they strengthen trust or decision-making.

Good candidates:

- a genuinely competitive catalog size;
- exact file-size presets;
- supported formats;
- task duration when speed is real and repeatable;
- language coverage when verified;
- no-signup / no-installation facts;
- concrete limits that users need before starting.

Avoid prominent numbers that mainly invite an unfavorable comparison.

Rule:

> Quantify advantages and required constraints. Do not quantify a disadvantage merely because the number is available.

## 5. Translate features into user outcomes

Technical facts are often proof, not the headline.

Prefer:

```text
Feature: Browser-local processing
Benefit: Your files never leave your device.
Proof: Processing happens locally in the browser.
```

```text
Feature: Exact target-size compression
Benefit: Meet strict upload limits without repeated trial and error.
Proof: Choose a target such as 50KB or 100KB.
```

Do not remove the technical fact when it helps credibility. Put the user outcome first, then use the implementation fact as proof.

## 6. Use searcher language before brand poetry

Prefer direct, task-specific language:

```text
Free Font Downloads
Steam Workshop Downloader
Compress Image to 50KB
Convert Markdown to PDF
```

Avoid replacing the primary task with vague brand copy such as:

```text
Unlock your creativity
Reimagine your workflow
Discover endless possibilities
The ultimate solution
```

Brand language may support the task. It should not obscure it.

## 7. Marketing claims require proof

Useful marketing is specific and defensible.

Prefer claims such as:

```text
No signup
Runs in your browser
Verified source
Clear license
Exact target size
TTF / OTF downloads
```

Avoid unsupported superlatives or guarantees:

```text
fastest
safest
100% secure
best in the world
unlimited
zero risk
```

Structured data, visible copy, product behavior, and legal/licensing statements must agree.

## 8. Curate instead of apologizing for scale

When a catalog is intentionally smaller than established competitors, do not lead with the raw count unless the count itself is competitive.

Do not write:

```text
149 curated font families
Although our library is smaller...
```

Prefer:

```text
Curated font collection
Clear licenses · Verified sources · Practical previews
```

The product may later surface a catalog count when scale becomes a positive signal.

## 9. Preserve factual and legal clarity

Marketing never overrides:

1. factual correctness;
2. legal or licensing requirements;
3. material product limitations;
4. pricing and eligibility clarity;
5. accessibility;
6. search intent.

When these conflict with promotional wording, the truthful constraint wins.

## 10. Reference products carefully

Competitor research can inform:

- page hierarchy;
- information density;
- page types;
- internal-link patterns;
- search vocabulary;
- proof placement;
- useful category models.

Do not copy competitor claims, catalog counts, unsupported positioning, or product-specific language.

Copy the structure of a successful decision path, not the competitor's marketing assertions.

## 11. Review questions

Before shipping public copy, ask:

- What keyword or search intent is this page mapped to?
- Is that intent still obvious in the title, H1, Hero, and body?
- What is the clearest user outcome?
- Why should the user choose this result instead of returning to search?
- What proof supports that reason?
- Did we expose a non-essential weakness or low number?
- Did we create an unnecessary comparison frame?
- Did we turn a technical feature into a user-relevant benefit?
- Are all claims true, visible, and consistent with product behavior?
- Is the CTA the natural next step for this intent?
