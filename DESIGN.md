# ShipLean interface language

ShipLean uses a compact operational interface rather than a conventional oversized SaaS landing page.

- Canvas: `#fafaf8`; working surfaces: white; borders: `#e5e6e1`.
- Primary text: `#171816`; supporting text: `#747770`.
- Ready and active states use muted green. Sandbox and unconfigured states use warm orange.
- Cards use 10–12px radii, 1px borders, and little or no elevation.
- Desktop navigation lives in a 256px sidebar. Mobile keeps a 64px utility header and removes the sidebar.
- Supporting UI stays at 10–14px. Large type is reserved for the public value proposition.
- Manrope and DM Mono remain bundled target-owned typography assets.

The visual language may borrow general density and layout patterns from mature operational dashboards, but ShipLean owns all identity, copy, icons, and product states.
